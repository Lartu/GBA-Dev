# Audio test assets

These files come from the `basic_sound` example distributed with devkitPro's
GBA Maxmod package:

- `FlatOutLies.mod`: tracker music example
- `Boom.wav`: one-shot sound effect
- `Ambulance.wav`: sound effect example

They are included here only as test material for the Maxmod integration. Replace
them with project-owned audio before distributing a game unless you have
separately confirmed the asset authors' licensing terms.
